LifeHackQuiz App

Overview
This is an Android quiz app developed using Kotlin.  
The app tests users on Life Hacks and Urban Myths.


Features
- Multiple-choice quiz (Hack vs Myth)
- Instant feedback after answering
- Score tracking
- Final score screen
- Review answers screen


Technologies Used
- Kotlin
- Android Studio
- XML Layouts
